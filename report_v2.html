PART 05
项目后价值收割 · 黄金窗口标准流程
项目结束后的10分钟是整个接诊流程中成交概率最高的窗口。顾客身体放松，防御心最低，情绪最正向，这时候说的话记忆留存率最高。
STEP 1
引导顾客说出效果
"佳佳，你感受一下肩膀这边，跟进来之前有没有不一样？" → 等她说，不要替她说。让顾客自己说出"有效果"，比你说一百遍都有力量。
STEP 2
解释今天效果的原理
"今天轻松的感觉，是因为我们把表层的筋膜做了第一次松解。你这个粘连的程度，大概3到5次会有真正持续的改善，今天是打开了一个口，后面会越来越好。"
STEP 3
埋下下次的钩子
"下次你来，我想把你的眼部也一起做。今天时间来不及，但你干眼症加上这么注重抗衰，眼部是一定要提上日程的。"
STEP 4
自然过渡到方案
"你现在大概多久来一次？我帮你看一下，如果做一个系统的周期，肩颈加上面部底层维护，效果会比单次叠加很多，我给你大概说一下我的建议……"

PART 07
逻辑总结 · 顾问能力训练路径
接诊失败的底层逻辑链
朱朱的思维模式（实际） 顾客来了 → 了解需求 → 介绍产品 → 希望成交
↳ 卡在"介绍产品→成交"之间，缺少关键一步
正确的思维模式 顾客来了 → 了解需求 → 诊断问题 → 放大痛点 → 说出根因 → 给出系统方案 → 建立信心 → 自然成交
缺失的那一步是：让顾客相信"我的问题在这里能被真正解决"。
没有这个信念，顾客永远只是来做一次性放松的。
朱朱能力提升训练路径
接待阶段当前问题需要训练的能力
破冰 赞美式破冰，慢热顾客防备增强 提问式破冰，让顾客多说，用提问代替赞美
需求挖掘 听到需求直接推产品 诊断式分析：确认根源 → 连锁影响 → 为何未解决 → 方案
产品推荐 介绍功能和成分 放大痛点 + 说出根因 + 给系统方案 + 建立信心
处理异议 顾客说不就放弃 识别真假异议，主动收缩反而建立信任
项目结束后 随顾客走，没有收割 固定的价值收割四步流程，5分钟决定下次是否成交
PART 08
关键 Case 复盘 · 逐句点评
每个关键时刻都包含：时间戳 + 原话 → 三层分析 → 正确话术。点击 ▶ 0:01:34 可跳转录音。
✓
破冰自然 · 主动关注细节 做到
"你的气色好好哦""你的形体保持的还是挺好的"
表层做法
赞美顾客气色好、形体好；察觉到顾客一直眨眼，主动提问是否干涩——观察力在线
值得保留
气氛轻松友好，顾客没有明显防御。观察到身体细节让顾客感受到被关注，这是信任的好起点
可优化方向
赞美后立即转化为信息收集："我看你身材保持得真好，是经常运动吗？还是有做什么调理？" 让赞美成为诊断切入的开关，而不是结束
✓
识别到斜方肌凸起 · 说出专业词汇 做到
"你这个地方黏连的是不是比较久了""无痛化解"
表层做法
主动观察到斜方肌凸起，说出了"筋膜粘连""无痛散结"专业词汇，方向正确
值得保留
身体观察能力没问题，专业词汇使用得当。顾客没有抵触，说明有基础信任
可优化方向
说出来了但没串联逻辑，需要补："为什么你之前的方式没解决 → 我们的原理 → 一个具体的预期" 这三条才构成完整说服链
1
精油选择拖了3分钟 · 失去主导权 遗漏
"闻不出来吗？要不我给你讲一下它的功能？"
表层问题
让顾客在多款精油间自行选择，顾问在旁边讲功效。顾客说"其实我也区别不了"——这是授权给你做决定的信号，不是让你继续教学
深层问题
没有主导权，把决策权完全交给了顾客。对慢热型顾客来说，选择太多 = 焦虑增加 = 信任降低
正确做法
顾客说肩颈痛的瞬间，直接主导："没关系，那我帮你选——你刚才说肩颈不舒服，迷迭香最适合你现在的状态，我们用它。"
2
顾客主动给痛点 · 没接住 遗漏
"那也可以选迷迭香，你喜欢闻这个迷迭香不？"
表层问题
顾客主动说"睡眠还好，我主要是肩颈痛"——给出了第一个核心痛点，但朱朱只是把它接成了"那选迷迭香"，把痛点降级成选品依据
深层问题
这是天然的诊断切入点，应该立刻进入"识别 → 命名 → 解释机制"的诊断逻辑，但顾问完全错过了
正确做法
"肩颈痛多久了？我看你斜方肌凸起的程度，不只是肌肉紧，是筋膜已经开始粘连了。你之前做过按摩是不是当天舒服，过几天又回来了？"
3
"你们东西好多" · 信任危机信号 遗漏
"洗脸，我们有面部，脸部，身体都有……"（继续介绍更多）
表层问题
顾客说"东西好多"，朱朱没有收缩，反而继续介绍更多项目——触发了顾客的防御反应
深层问题
"东西好多"是信任危机信号：前面的铺垫没有建立足够的专业感，顾客已经进入"被推销"的心理状态
正确做法
听到这句立刻收缩："佳佳你放心，我不会都推给你。我就觉得你今天肩颈这个问题最需要解决，其他的先不说——等你做完这次感受到了，我们再聊别的。"
4
眼部护理被拒"还没睡醒" · 假异议被当真 做错
"你今天要不要做个眼部护理嘛？" → 被拒 → "那你下次来可以尝试一下"
表层问题
用"要不要"这种给顾客退路的句式提议，顾客说"还没睡醒"就直接放弃了。两个连续失误：提议方式太弱 + 接受假异议
深层问题
"还没睡醒"是模糊借口，不是真实拒绝。顾客没说"不要/没钱/不感兴趣"，只给了一个不疼不痒的理由。这种软拒绝是可以推破的
正确做法
"正因为还没睡醒，做完你会更清醒——眼睛舒服了整个人状态都不一样。就加30分钟，今天正好试一次，做完你自己感受一下，做了之后你会谢我的。"
5
顾客提到医美消费习惯 · 最大信号没接住 遗漏
顾客提到打除皱针、童颜针，朱朱只是简单回应
表层问题
顾客主动提及医美消费经历（除皱针、童颜针、超皮秒、英诺小棕瓶），这是高消费意愿 + 待解决问题的最大信号

一句话总结整个 Case
刘佳佳是一个愿意花钱、消费成熟、专业信任驱动的高潜力顾客。
朱朱用了一套"好服务员"思维接待了一个需要"顾问式销售"的顾客。

回店切入话术
优先从干眼症切入：
"佳佳，我还记得上次你说眼睛容易干涩，这几天好一点没有？我这两天一直在想这个问题，你戴美瞳加上干眼症，泪膜在持续受损，你其实现在就是最佳干预时机，今天我想给你做一个眼部护理，做完你自己感受一下。"
肩颈第二次到店：
"上次第一次做完之后，你自己感觉怎么样？有没有比做之前轻一点？我跟你说，第一次是打开通道，真正的改变从第三次开始，我们来继续做吧。"

朱朱接待的刘佳佳，做的好的破冰流程是有，但这个顾客性格慢热可能不适合表扬赞美太多，反而防备。 召需求顾客说肩颈、上半身紧，可以帮助顾客诊断分析一下，怎么调理，之前是不是只管一会儿，效果不连续，分析说出咱们品牌的解决方案。 顾客是个医美爱好者，喜欢医美解决，可以和顾客互动了解有没有医美没有解决的问题，不诋毁但是一定要突出我们品牌价值——无伤害美学和医美的区别。 就是顾客说我们项目多的时候，这个时候对于前面推销建议的两三个项目感觉是在推销，这个时候要通过选品和结构方案给顾客信心，讲一下我们的品牌核心技术。 顾客出来没有对于今天做的项目价值塑造，问顾客感觉引导效果，自然就被顾客牵着走随便闲聊赶时间就走了，丢失了铺垫种草的机会，没有这些机会就很难有下次成交。 整个过程顾客干眼症、顾客抗皱、顾客肩颈不舒服几个痛点都没有一个抓住给顾客解决的信心，方案和原理都很表面被顾客牵着走，所以很难成交方案大卡。必须抓住一个点深入给顾客带来价值，才能有后续的其他项目机会，否则就是放松简单组个项目，顾客很难培养品牌性。
